# 🎁 懸賞応募アシスタント

X（旧Twitter）の懸賞ツイートへの応募を楽にする、**完全無料**の Web アプリです。

- X API・有料プラン・AI APIは不要（費用0円）
- 応募条件の読み取り、引用文の作成、履歴の管理を自動化
- フォロー・リポスト・いいね・引用は、X の公式の確認画面（Web Intent）を開き、**あなたが確定ボタンを押す**方式
  → 自動いいね・自動フォローは X の規約違反なので行いません。そのぶん凍結リスクを最小にしています。

## できること

| 機能 | 内容 |
|---|---|
| 懸賞検索 | 絞り込み済みの X 検索をワンタップで開く（条件は設定で変更可） |
| 条件解析 | URL を貼るだけで、フォロー先・リポスト・いいね・引用・指定ハッシュタグ・締切・賞品を読み取る |
| 対象外の除外 | リプライ・DM・LINE登録・アプリ・外部フォーム・購入が必要なものは自動でスキップ |
| 安全チェック | 手数料・口座情報・外部サイト誘導などの詐欺ワード、ブラック／ホワイトリストで判定 |
| 引用文の作成 | 指定キーワードを必ず含む自然な一文をテンプレートから作成（同じ文の連続を避ける） |
| 応募ボタン | 必要な操作だけをボタンで表示。全部押すと自動で「応募済」 |
| 凍結防止 | 1日の応募数・フォロー数の上限、フォロー総数の警告 |
| フォロー整理 | 締切から14日たった落選キャンペーンのアカウントを一覧表示 |
| 当選管理 | 応募済・当選・落選の履歴 |

## 使い方

### 1. インストール（初回のみ）
Python 3.10 以上が必要です。
```bash
pip install -r requirements.txt
```

### 2. 起動
```bash
python -m kensho
```
ブラウザで http://127.0.0.1:5000 を開きます。

スマホから使う場合（自宅の Wi-Fi 内のみ）：
```bash
python -m kensho --lan
```
スマホのブラウザで `http://<PCのIPアドレス>:5000` を開きます。
※パスワード保護はないので、公衆Wi-Fiでは `--lan` を使わないでください。

### 3. 応募の流れ
1. ホームの「🔍」ボタンで懸賞ツイートを探す
2. 気になるツイートの URL をコピーして貼り付け →「解析する」
3. 安全チェックと応募条件を確認（初めての主催者はプロフィールで認証マークを確認し、「公式として登録」）
4. 引用が必要なら引用文を確認（お題がある場合は回答を書き換えて保存）
5. 応募ボタンを上から順にタップ → X の画面で確定

本文を自動取得できない場合（X の仕様変更・非公開アカウントなど）は、「本文を貼り付け」欄にツイート本文を貼ってください。

## 注意
- 自動解析はルールベースなので完璧ではありません。応募前に元ツイートの条件と見比べてください。
- 上限の初期値（応募20件/日・フォロー30件/日）は控えめな目安です。設定画面で変更できます。
- 応募規約で禁止されている方法（複数アカウントでの応募など）は使わないでください。
- 当選DMでの手数料請求・外部サイトへの個人情報入力は詐欺の典型です。
