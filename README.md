# 🎁 懸賞応募アシスタント（スマホ完結・完全無料）

X（旧Twitter）の懸賞ツイートへの応募を楽にする、**スマホのブラウザだけで動くアプリ**です。

- PC・サーバー・X API・AIはすべて不要（費用0円）
- データはスマホの中だけに保存（外部に送信しません）
- ホーム画面に追加すると、アプリのように使えます
- 応募の最終操作は X の公式確認画面で**本人がタップ**します
  → 自動いいね・自動フォローは X の規約違反なので行いません。凍結リスクを最小にしています。

## できること

| 機能 | 内容 |
|---|---|
| 懸賞検索 | 絞り込み済みの X 検索をワンタップで開く（条件は設定で変更可） |
| 条件解析 | URL を貼るだけで、フォロー先・リポスト・いいね・引用・指定ハッシュタグ・締切・賞品を読み取る |
| 対象外の除外 | リプライ・DM・LINE登録・アプリ・外部フォーム・購入が必要なものは自動でスキップ |
| 安全チェック | 手数料・口座情報・外部サイト誘導などの詐欺ワード、公式／ブラックリストで判定 |
| 引用文の作成 | 指定キーワードを必ず含む自然な一文を作成（同じ文の連続を避ける、その場で編集可） |
| 応募ボタン | 必要な操作だけをボタンで表示。全部押すと自動で「応募済」 |
| 凍結防止 | 1日の応募数・フォロー数の上限、フォロー総数の警告 |
| フォロー整理 | 締切から14日たった落選キャンペーンのアカウントを一覧表示 |
| 当選管理・バックアップ | 応募済・当選・落選の履歴、データの書き出し／読み込み |

## スマホでの使い方

1. 公開された URL（下記「公開方法」）をスマホのブラウザで開く
2. 「ホーム画面に追加」する
   - iPhone：Safari の共有ボタン →「ホーム画面に追加」
   - Android：Chrome のメニュー →「ホーム画面に追加」／「アプリをインストール」
3. 「🔍」ボタンで懸賞ツイートを探す
4. ツイートの「共有 → リンクをコピー」→ アプリの「貼付」→「解析する」
   - Android でホーム画面に追加した場合は、X の「共有」から直接このアプリを選べます
5. 安全チェックと応募条件を確認し、応募ボタンを上から順にタップ → X の画面で確定

本文を自動取得できない場合は、「本文を貼り付け」欄にツイート本文を貼ってください。

## 公開方法（無料）

`web/` フォルダは HTML・JavaScript だけでできているので、無料の静的ホスティングにそのまま置けます。

### A. GitHub Pages（リポジトリを公開にする場合）
1. GitHub でリポジトリを **Public** にする（無料プランでは非公開リポジトリから Pages を公開できません）
2. Settings → Pages → Source を **GitHub Actions** にする
3. `main` ブランチにマージすると `.github/workflows/pages.yml` が自動で公開
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` で使えます

### B. Netlify / Cloudflare Pages（リポジトリを非公開のままにする場合）
無料アカウントを作り、このリポジトリを連携して公開フォルダに `web` を指定します（ビルドコマンドなし）。

公開されるのはアプリのプログラムだけで、応募履歴などのデータは各自のスマホの中に保存されます。

## 注意
- 自動解析はルールベースなので完璧ではありません。応募前に元ツイートの条件と見比べてください。
- データはブラウザ内に保存されます。ブラウザのデータを消すと消えるので、設定画面からときどきバックアップしてください。
- 上限の初期値（応募20件/日・フォロー30件/日）は控えめな目安です。
- 当選DMでの手数料請求・外部サイトへの個人情報入力は詐欺の典型です。
