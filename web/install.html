🎁 懸賞アシスタント

X上でワンタップ応募する設定

この設定をすると、Safari（Android は Firefox）で X を開くだけで、懸賞ツイートの下に「🎁 懸賞」の枠と「応募する」ボタンが自動で表示されます。URL のコピーや貼り付けは不要です。

  • ボタンを押すと、そのツイートに必要な「フォロー・いいね・リポスト」を順番に実行します
  • 引用が必要な場合は、指定キーワード入りの文が入力された投稿画面を開きます。内容を確認して「ポスト」を押してください
  • LINE登録・DM・購入などが必要な懸賞や、詐欺の疑いがあるものにはボタンを出しません
  • 画面左下の 🎁 ボタンから「まとめて検索」と設定ができます
  • 無料です。X の API やサーバーは使いません

iPhone の場合

  1. App Store で無料アプリ 「Userscripts」（開発者: Justin Wasack）をインストール
  2. 「設定」アプリ → 「アプリ」→「Safari」→「機能拡張」→「Userscripts」をオンにし、x.com を「許可」にする
  3. Safari で下のボタンを開く → アドレスバーの「ぁあ」（または 🧩）→「Userscripts」→ インストール
スクリプトを開く

※ X アプリではなく Safari で x.com を開いて使います。リンクから開くと X アプリに飛ぶ場合は、Safari のアドレスバーに「x.com」と直接入力してください（ブックマーク推奨）。

Android の場合

  1. Google Play で Firefox をインストール
  2. Firefox のメニュー →「拡張機能」→ Tampermonkey を追加
  3. Firefox で下のボタンを開く → Tampermonkey の画面で インストール
スクリプトを開く

※ Firefox で x.com を開いて使います。

注意

  • ボタンを押したときだけ動きます。勝手に応募することはありません
  • 1日の応募数・フォロー数に上限があります（初期値：応募20件・フォロー30件。🎁 → 設定で変更可）
  • スクリプトでボタンを押す方式のため、X の画面が変わると一部の操作がうまくいかないことがあります。✗ が出た操作は手動で行ってください
  • X は自動化された操作を制限しています。短時間に大量に応募すると、凍結などの制限を受けるおそれがあります。上限は控えめにしてください
  • 新しい版が出たら、このページの「スクリプトを開く」からもう一度インストールすると更新できます（Tampermonkey は自動で更新されます）
