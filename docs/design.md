# 懸賞応募アシスタント 設計書

## 1. 要件
| 項目 | 決定内容 |
|---|---|
| 運用アカウント | 個人アカウント1つ |
| 対象 | 公式アカウントのプレゼント懸賞ツイート（「その場で当たる」「プレゼントキャンペーン」「抽選で」など） |
| 応募方法 | フォロー・リポスト・いいね・引用リポストだけで完結するもののみ |
| 引用文 | 指定キーワードやハッシュタグを含む、違和感のない一文 |
| 通知・操作 | スマホのブラウザだけで完結（PWA、ホーム画面に追加可） |
| 費用 | 完全無料（X API 有料プランなし、AI APIなし） |
| 凍結対策 | 規約で禁止される自動いいね・自動フォローは行わない。最終操作は本人が X の確認画面で行う |

## 2. 構成
サーバーを持たない静的Webアプリ（PWA）。すべての処理をスマホのブラウザ内で行う。
```
[スマホのブラウザ]
  web/index.html … 画面の土台・PWA設定
  web/app.js     … 画面描画・操作・localStorageへの保存・バックアップ
  web/logic.js   … 条件解析・引用文生成・安全チェック・Intent URL（純粋関数、Nodeでテスト）
  web/sw.js      … オフライン起動用キャッシュ
      │
      ├─ publish.twitter.com/oembed（JSONP）… 本文取得（無料・認証不要。失敗時は手動で貼り付け）
      └─ x.com/intent/*                    … フォロー・RT・いいね・引用の確認画面
```
- 公開先：GitHub Pages（`.github/workflows/pages.yml`）または Netlify / Cloudflare Pages の無料枠
- Android：manifest の `share_target` により、X の「共有」から直接受け取れる

## 3. 処理フロー
1. **探す**：設定のキーワードを `buildSearchQuery()` で1本の OR 検索にまとめ、`x.com/search`（新しい順・直近N日）を開く
2. **登録**：URL を貼る → oEmbed で本文取得（失敗時は手動で貼り付け）
3. **解析**：`parseCampaign()` で条件を抽出し、対象外なら `skipped`
4. **判定**：`checkSafety()` で `safe` / `unknown` / `danger`。`danger` は応募ボタンを出さない
5. **引用文**：`buildQuote()` で生成し、`validateQuote()` で必須語・文字数・お題の未回答を検査
6. **応募**：Intent ボタンを押すたびに キャンペーンの `actions` に記録。必要な操作がそろったら `entered`
7. **事後**：当選・落選を記録。締切から14日たった落選分のフォローを整理候補に出す

## 4. 状態遷移
```
new（未応募） ─┬→ entered（応募済） ─┬→ won（当選）
               │                     └→ lost（落選）
               └→ skipped（対象外・手動スキップ・ブラックリスト）
```

## 5. 解析ルール（logic.js）
- 前処理：NFKC 正規化（全角の＃＠や数字を半角に）
- 当選連絡の行（「当選者にはDMでご連絡」など）は応募条件の判定から除く
- 対象外の条件：リプライ応募、DM応募、LINE登録、アプリDL、外部フォームやアンケート、購入やレシート、会員登録
- 「引用リポスト」は通常のリポストとして数えない
- フォロー先：「フォロー」を含む行と、その直後の @ だけの行に出てくる @ID。見つからなければ主催者
- 引用キーワード：引用やハッシュタグ指示の行にある #タグ、「〇〇」と入れて のような指定語
- お題：「教えて」「お答え」などを含む行。引用文に回答欄を入れ、本人が入力するまで投稿できない
- 締切：本文中の日付の最大値（時刻がなければ 23:59、年がなければ推定）

## 6. 凍結防止の設計
| 対策 | 内容 |
|---|---|
| 自動操作なし | すべての操作は X 公式の確認画面で本人が確定する |
| 1日の応募上限 | 既定 20 件。超えたら応募ボタンを非表示 |
| 1日のフォロー上限 | 既定 30 件。超えたらフォローボタンを停止 |
| フォロー総数の警告 | 既定 4,000 件で警告し、整理を促す |
| 引用文の重複回避 | 直近6件で使ったテンプレートは使わない |
| フォロー解除 | 一括の自動解除はせず、一覧から1件ずつ手動で解除 |

## 7. データ（localStorage `kensho-v1`）
| キー | 用途 |
|---|---|
| campaigns | キャンペーン（本文、解析結果、引用文、状態、締切、実行した操作） |
| follows | フォロー中アカウントと、紐づく最新のキャンペーン |
| whitelist / blacklist | 公式アカウント・ブラックリスト |
| settings | 上限値・検索条件 |

設定画面から JSON でバックアップと復元ができる。
